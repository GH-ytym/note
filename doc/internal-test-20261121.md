# Note 校园网 / Tailnet 内测

## 安装与登录

安装包：Note-Server-Setup-0.5.0.exe（2026-11-21 构建）。这是 Windows x64 服务器版，不能与此前同名旧包仅凭版本号区分，请使用本轮分享目录中的文件及 SHA256SUMS。

1. 连上校园网，先用浏览器打开 https://files.gis.epawse.xyz/p/note/ 确认可以访问，再安装客户端。
2. Tailnet 用户需把 files.gis.epawse.xyz 解析到 100.101.86.29；仅连接 Tailnet 不保证域名入口可达。不要改用 HTTP 或 IP 地址绕过 HTTPS。
3. 每位测试者自行注册独立账号，不共享密码。安装包不携带数据库、账号或密钥。
4. 暂用测试日程和测试内容。首轮不验收群解散，该按钮已隐藏；群主转让退出仍存在，但建议在独立测试群验证。
5. 安装包未做代码签名，Windows 可能提示发布者未知；先核对提供者和 SHA256，不要关闭系统安全防护。

服务器版加载服务器网页：网页/后端更新不需要重装；桌面外壳更新才需要重发安装包。

## 两人一起验收

由 A 建立“需要审核”的测试群，B 使用另一个账号。建议至少使用两台机器。

| 操作 | 预期 | 结果 |
|---|---|---|
| B 输入六位群号并申请；A 同意 | A 收到申请通知，审核状态与未读数更新；B 收到结果并能进入群 | 待验收 |
| 另建申请并拒绝 | 申请状态正确；申请人没有获得群访问权 | 待验收 |
| A 创建 Todo 和 Event，B 查看相同群/日期 | B 不手动刷新也能看到内容；重复日程展开正确 | 待验收 |
| A 修改标题、时间，再移到 B 当前范围之外 | B 显示新内容，旧位置移除 | 待验收 |
| A 删除记录 | B 的所有相关实例移除 | 待验收 |
| B 标记某次 Todo 完成，再取消 | B 自己的完成状态正确，其他成员看到完成名单变化 | 待验收 |
| A 授予/撤销 B 的编辑权限 | 后端允许/拒绝相应操作；权限详情可重新打开核对 | 待验收 |
| B 隐藏日历/切换标签，A 修改；B 返回 | 立即校正当前范围，不被旧请求覆盖 | 待验收 |
| B 断网，A 修改或删除；B 恢复网络 | 自动重新同步，包含遗漏的删除 | 待验收 |
| B 不操作，观察可见日历 | 每次查询完成后约 60 秒校正；后台刷新不清空内容 | 待验收 |
| B 退出测试群 | B 无法再查询或修改该群记录 | 待验收 |
| 上传、更换个人头像，重新登录 | 图片可加载；群图标保持颜色与首字符样式 | 待验收 |
| 关闭/重新打开客户端、调整窗口与小窗 | 登录完整面板，窗口控件和切换正常 | 待验收 |

推送当前触发“当前群 + 当前日期范围”的刷新，不是单条实例查询；离线恢复依赖查询成功。已经打开的详情页不是本轮日历主面板同步的验收对象，必要时重新打开核对。
