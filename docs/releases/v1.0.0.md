# Note v1.0.0

从单机日历升级为可在多台电脑上使用的协作应用。

## 下载与使用

- `Note-Server-Setup-1.0.0.exe`：Windows x64 安装版。
- `Note-Server-1.0.0.exe`：Windows x64 便携版。
- `SHA256SUMS.txt`：安装包 SHA256 校验值。
- 源码压缩包由 GitHub 自动提供；自部署请参考仓库 `deploy/cloud/README.md`。

本次桌面包连接 https://124.220.23.245/ ，需要联网，无需在使用者电脑安装数据库或 Redis。首次使用请注册账号。服务器版与旧单机版为不同应用，旧本地数据不会自动上传或合并。Windows 包尚未签名；macOS 成品包不包含在本次发布中。

## 主要功能

- 注册、登录、恢复会话与默认个人空间。
- 群组资料、六位群号查找、自由加入与入群申请审核。
- 共享待办与日程、成员编辑权限、个人完成状态。
- 年／月／周／日视图、时间轴、24 小时时钟与桌面小窗。
- 顶部多标签页、右侧新建表单与日历联动选日期。
- 实时通知、分页、批量已读及同意／拒绝操作。
- 日历变更推送、通知重连同步和日历低频刷新补偿。
- 头像上传、更换与移除，云端使用腾讯云 COS。

## 已知边界

- 指定用户邀请仍未实现；请使用自由加入或需要审核的群组。
- 带历史通知的群组暂不能解散：数据库拒绝物理删除，事务回滚，数据保留。
- 重复事项暂不支持仅对某一次单独改期。
- 不提供邮箱找回密码、客户端自动升级或服务可用性承诺。
- 本次未迁移旧单机版及课题组服务器的数据。
