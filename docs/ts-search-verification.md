# TypeScript、搜索与日视图验证

验证日期：2026-09-11。桌面交互使用独立临时 userData 和 SQLite 数据库，未向用户日程添加测试记录。

## 实现

- 前端运行代码与 Vite 配置迁移为 TypeScript；启用 strict、noUnusedLocals、noUnusedParameters。构建先执行类型检查。API、配置、IPC、组件属性和表单状态均有类型定义。
- 三种搜索共用仓库查询、评分、稳定排序及分页：精确标题 100、标题前缀 80、标题包含 60、正文包含 20；其次按更新时间、类型、ID 排序。通配符作为字面文本匹配。
- 顶部搜索每次文本变化同时请求 Todo/Event，取消过期请求；快速结果上下分组各自滚动，详细结果支持分栏、合并与翻页。
- 选择搜索结果按 Asia/Shanghai 解析 starts_at，定位首次发生日期；年视图切换月视图，其余视图保持。目标闪烁两次。
- 搜索快速面板与详细面板复用单个副面板位置。打开搜索关闭原生副窗口，打开新建、详情、设置等原生副窗口关闭搜索。浏览器专注编辑也复用已有副窗口。
- 天视图提供时间轴、时钟、标签三种模式；标签列表参考 b0d3205 的 DayAgendaPanel 分组实现，增加独立 Event 组。
- 首选项新增搜索分栏默认值、天视图和小窗默认样式；配置项新增每类／每页搜索上限。默认分栏、标签、8 条。
- 时间选择器参与表单布局并自动滚入可见区域。小窗把手使用指针屏幕坐标通过 IPC 移动原生窗口，避免 CSS 拖动失效与异步取坐标竞态。

## Electron 交互验证

- 使用真实 API 创建 12 条 Todo 和 12 条 Event，默认快速面板返回 8+8 条，详细分栏布局两列可见；合并模式请求 /api/search/all 并分页。
- 年视图选择搜索结果后为 2026 年 10 月，选中日期 2026-10-12；周／日视图保持原视图，Todo/Event 均出现目标高亮，动画迭代数为 2。标签及 SVG 时钟定位均通过。
- 延迟旧关键词请求后立即输入新词，最终只显示新词结果；每次变化均请求 Todo/Event。Escape 从结果按钮返回搜索框并关闭结果。
- 新建副窗口打开时搜索替换它，窗口数量由 2 变为 1；详细搜索扩展仍使用同一副面板。
- 首选项改为合并、上限改为 3 后，快速结果 3+3，详细默认合并 3 条；appearance.json 保存对应设置。
- 650px 高表单的时间面板底部为 639.5px；300px 高表单底部为 289.5px，无需手动向下滚动。
- 380px 宽主窗口无水平溢出，三种日视图模式和工具栏可见。
- Windows 真实鼠标拖动小窗：原生窗口坐标从 (1546, 658) 变为 (1456, 756)，尺寸保持 360×360。
